# Clause Craft

Spellbook-style contract review that sits beside your document — built for CRE leases & PSAs.

## Live / local
- Local: `/workspace/clause-craft/index.html`
- Live: https://raw.githack.com/Chadnasir/clause-craft-cre/main/index.html
- Repo: https://github.com/Chadnasir/clause-craft-cre

## What it does
- Word-like editor + docked right sidebar (Review / Clauses / Ask / Summary)
- CRE clause detection (indemnity, liability, termination, assignment, NNN, insurance, etc.)
- Accept → in-doc redline (strike + insert)
- Plain-language summary + keyword Ask with sources
- Demo Spectrum Suite 240–style lease; upload .txt/.md; export / print

## vs Spellbook
Spellbook is a Microsoft Word add-in with cloud AI, Playbooks, market benchmarks, and Associate for multi-doc matters (custom per-seat pricing, 7-day trial). Clause Craft is a browser demo: no Word install, CRE-tuned heuristics, offline, free to open — not a law-firm platform and **not legal advice**.

## vs typical Grok Build
Broker brand, real redlining in the page, CRE clause library, Ask + Summary, persistence — not a generic chat toy.

Demo only — not legal advice. Have counsel review before signing.
